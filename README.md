# Poox

لعبة جماعية خفيفة وسريعة تعمل مباشرة من المتصفح (بدون باك-إند وبدون إعداد بيئة تطوير).

## تشغيلها بسهولة **بدون بيئة عمل**

### الخيار الأسهل جدًا (بدون أي أوامر)
1. نزّل المشروع كملف ZIP.
2. فك الضغط.
3. افتح ملف `index.html` بالضغط المزدوج.
4. اكتب أسماء اللاعبين واضغط **Start Poox**.

> هذا الخيار يكفي لمعظم المستخدمين لأن اللعبة عبارة عن HTML/CSS/JS فقط.

---

### خيار النشر السريع (رابط مشاركة للجوالات)
إذا تريد رابطًا يشتغل على أي جهاز بدون تثبيت شيء:

1. افتح [Netlify Drop](https://app.netlify.com/drop).
2. اسحب مجلد المشروع (أو الملفات الثلاثة: `index.html`, `styles.css`, `script.js`).
3. سيعطيك الموقع رابطًا مباشرًا للعبة.
4. شارك الرابط مع المجموعة.

---

## الملفات الأساسية
- `index.html`: الواجهة.
- `styles.css`: التصميم.
- `script.js`: منطق اللعبة.

## ملاحظات
- تحتاج متصفح حديث (Chrome / Edge / Safari / Firefox).
- لا تحتاج قاعدة بيانات أو تسجيل دخول.
